# SCI for AI & Sustainable Agentic Workloads Skill

An Agent Skill synthesised from the Green Software Foundation [Reference Implementations](https://github.com/Green-Software-Foundation/reference-implementations):

- `tools/gsf/mcp-sci` — Carrying SCI for AI disclosures and per-call attributions over the Model Context Protocol (MCP)
